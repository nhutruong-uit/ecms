Xem web app

Ứng dụng chạy trên GitHub Codespaces (máy ảo của GitHub). Thầy và các bạn chỉ cần mở link nhóm gửi bằng trình duyệt (Safari, Chrome, Edge – macOS, Windows hay điện thoại đều được), ở mạng nào cũng được, không cần tài khoản GitHub, clone repo hay cài SQL Server.

Người xem

  1. Mở link nhóm gửi, dạng https://<tên-codespace>-8501.app.github.dev
  2. Đăng nhập bằng một tài khoản demo bên dưới; danh sách này cũng hiện ngay ở trang Đăng nhập
Tài khoảnMật khẩuVai trò
quanlyEcms@2026Quản lý trung tâm (mọi chi nhánh)
giaovuEcms@2026Giáo vụ CN01
ketoanEcms@2026Kế toán CN01
giaovienEcms@2026Giáo viên
hocvienHocvien@2026Học viên

Dữ liệu là dữ liệu mẫu, có thể thử thêm, sửa, xoá thoải mái: nhóm dựng lại CSDL là về như ban đầu.

Nhóm mở ứng dụng (Codespaces)

  1. Trang repo → Code → Codespaces → mở Codespace cũ hoặc Create codespace on main. Lần đầu chờ khoảng 5 phút (cài thư viện, dựng CSDL), lần sau khoảng 1 phút
  2. Terminal tự chạy .devcontainer/start.sh: SQL Server 2025 → CSDL ECMS → Streamlit ở cổng 8501
  3. Tab Ports → cổng 8501 → chuột phải → Port Visibility → Public → Copy Local Address, gửi link vào nhóm chat
  4. Giữ tab Codespace mở trong lúc mọi người xem; xong thì Stop codespace để không tốn giờ miễn phí

Không vào được?

  • Người xem gặp trang đăng nhập GitHub: cổng 8501 còn Private, làm lại bước 3
  • Codespace ngủ (mặc định sau 30 phút không ai dùng): mở lại Codespace, ứng dụng tự chạy lại, link giữ nguyên
  • Lỡ đóng terminal: chạy bash .devcontainer/start.sh; dữ liệu về như ban đầu: RESET_DB=1 bash .devcontainer/start.sh

Chi tiết: docs/SETUP.md mục 6. Vẫn chạy được trên laptop cho người xem cùng mạng Wi-Fi: streamlit run app/main.py rồi gửi link Network URL (xem mục 4).

Công nghệ & cấu trúc repo

Theo đúng công cụ trong đề cương (SQL Server Management Studio) và bài thực hành 5 (Python + pyodbc + Streamlit).

SQL Server 2022

HQT CSDL chính, dùng T-SQL cho procedure, function, trigger, cursor, XML, login/role, backup. Windows dùng SSMS; macOS chạy Docker.

Python · Streamlit

Ứng dụng web: menu bằng st.navigation, form bằng st.form / st.data_editor, biểu đồ bằng Plotly. Kết nối DB qua pyodbc + ODBC Driver 18.

pandas · reportlab · openpyxl

Xử lý dữ liệu báo cáo, xuất PDF (thay Crystal Report) và Excel.

draw.io · Mermaid

ERD (Chen), Class Diagram, sơ đồ quy trình nghiệp vụ, cây menu.

MongoDB

Demo chuyển đổi sang CSDL phi quan hệ ở Chương 5 (chạy bằng Docker).

GitHub

Issues + Project để giao việc, Pages để công bố kế hoạch, lịch sử commit ghi đúng người phụ trách.

Quy ước làm việc

Mỗi thành viên phụ trách trọn các task của mình, từ phân tích, thiết kế, viết mã đến phần báo cáo tương ứng. Như (nhóm trưởng) review, tích hợp mã của các thành viên vào repo và chạy kiểm thử chung; mỗi commit ghi tên thành viên phụ trách phần đó (scripts/commit-as.sh), để lịch sử git thể hiện đúng phân công.

Quy trình một task

  1. Tạo nhánh theo task: t11-stored-procedure
  2. Commit bằng tên người phụ trách: scripts/commit-as.sh phu -m "feat(db): sp_DangKyHoc (#11)"
  3. Mở Pull Request, mô tả có Closes #11, đính kèm ảnh kết quả
  4. Nhóm trưởng review → merge vào develop → tick checklist, đóng issue, chuyển thẻ Project sang Done

Definition of Done

  • Script SQL chạy lại được từ đầu (DROP … IF EXISTS), chú thích tiếng Việt
  • Có ảnh chụp kết quả và mục báo cáo tương ứng trong report/
  • Có phần so sánh / đánh giá kèm số liệu khi phù hợp (theo rubric A4)
  • Tick đủ checklist trong issue; PR đã merge

Mẫu commit

feat tính năng · db script CSDL · docs tài liệu/báo cáo · fix sửa lỗi · chore việc lặt vặt. Ví dụ: db(views): thêm vw_CongNoHocVien (#16)
